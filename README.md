# AI Marketing Assistant

An AI-powered marketing assistant built with ASP.NET Core and Hugging Face.

## Features

- Multi-language input and AI-generated output
- Users can choose their preferred language
- Flexible campaign settings including budget, campaign goal, and campaign duration
- Analyze marketing data from CSV files
- Generate AI-powered marketing insights
- Create marketing campaign ideas
- Generate marketing content
- Simple and user-friendly web interface

## Setup

1. Clone the repository.
2. Open the project in Visual Studio.
3. Add your Hugging Face API Key in `appsettings.json`.
4. Run the project using Visual Studio.

## API Configuration

The project uses the Hugging Face API.

Add your own API key to the `ApiKey` field in `appsettings.json`.

Do not publish your API key publicly.
